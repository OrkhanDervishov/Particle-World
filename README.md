<h4>Build and Run</h4>

<h4>Windows</h4>

Put SDL2.dll to the main directory and run
```
make windows
```
or
```
build.bat
```

<h4>Linux</h4>

NOTE: at least in ubuntu it must work

Install SDL2
```
make linux
```
or
```
./build.sh
```
